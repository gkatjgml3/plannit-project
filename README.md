# 📅 PLANNIT

> **사진 한 장으로 시작하는 AI 일정 관리 서비스**

학교에서 받은 수행평가 안내문, 시험 안내 자료, 공지문 등의 이미지를 업로드하면 AI가 일정 정보를 추출하고, 사용자의 확인을 거쳐 캘린더에 등록해 주는 모바일 최적화 웹 서비스입니다.

> 현재 상태: 초기 기획 및 UI/UX·프론트엔드 설계 단계입니다. 아래 구조와 기능은 개발 목표를 포함하며, 구현 완료 여부는 [개발 현황](#-개발-현황)에서 관리합니다.

## 📌 프로젝트 소개

학생들은 학교 공지에 흩어진 일정 제목, 날짜, 시간, 장소, 준비물과 알림을 캘린더에 하나씩 입력해야 합니다. 여러 일정이 겹치는지 직접 확인해야 하고, 할 일과 일정이 분리되어 우선순위를 잡기 어렵거나 조별 과제 일정을 구성원 모두에게 다시 전달해야 하는 문제도 있습니다.

PLANNIT은 다음 흐름으로 이 문제를 해결합니다.

```text
📷 안내문 이미지 업로드
        ↓
🤖 Gemini AI 이미지 분석
        ↓
📄 하나 이상의 일정 정보 추출
        ↓
🔍 사용자 확인 및 수정
        ↓
📅 캘린더 등록
        ↓
🔔 알림 · 그룹 공유 · 준비 계획 확인
```

AI의 결과를 즉시 확정하지 않고 사용자가 먼저 검토하도록 하여, 흐린 사진이나 복잡한 문서에서 발생할 수 있는 인식 오류를 줄입니다.

## 🎯 대상 사용자와 기대 효과

- 수행평가, 시험, 과제, 학사 일정을 자주 관리하는 학생
- 반, 동아리, 스터디, 조별 과제 일정을 함께 관리하는 구성원
- 반복적인 일정 입력이 번거롭거나 일정 관리가 어려운 사용자

| 기대 효과 | 설명 |
|---|---|
| 입력 시간 절약 | 사진 한 장에서 여러 날짜의 일정을 한 번에 추출합니다. |
| 일정 누락 예방 | 시험·수행평가·과제 일정을 모아 보고 알림으로 다시 확인합니다. |
| 공유 편의 향상 | 그룹 구성원이 같은 최신 일정을 확인할 수 있습니다. |
| 학습 계획 개선 | 마감일까지 필요한 준비 일정을 나누어 계획할 수 있습니다. |

## ✨ 주요 기능

### 🖼️ 이미지 기반 일정 등록

- 수행평가 안내문, 공지문, 시험 안내 자료 이미지 업로드
- 한 이미지에 포함된 여러 일정 일괄 추출
- 등록 전 원본 이미지와 분석 결과 비교·수정

### 🤖 AI 일정 분석

Gemini API의 이미지 이해 기능과 구조화된 출력을 사용하여 비정형 안내문을 일정 데이터로 변환합니다.

- 일정 제목
- 시작·종료 날짜 및 시간
- 장소
- 준비물
- 상세 내용
- 반복 여부와 알림 정보

구조화된 출력은 형식을 일정하게 만드는 데 도움을 주지만 값의 정확성까지 보장하지는 않으므로, 서버에서 스키마와 날짜를 검증하고 사용자의 확인 후 저장합니다.

```json
{
  "events": [
    {
      "title": "수학 수행평가",
      "startAt": "2026-09-15T10:00:00+09:00",
      "endAt": "2026-09-15T10:50:00+09:00",
      "location": "1학년 3반 교실",
      "materials": ["필기구", "자"],
      "description": "도형 단원 평가"
    }
  ]
}
```

관련 공식 문서: [Gemini 이미지 이해](https://ai.google.dev/gemini-api/docs/image-understanding), [Gemini 구조화된 출력](https://ai.google.dev/gemini-api/docs/structured-output)

### 📅 캘린더 및 일정 관리

- 분석 결과를 캘린더에 등록
- 등록된 일정 조회·수정·삭제
- 겹치는 일정과 이동 시간을 고려할 수 있도록 충돌 정보 표시

### 🔔 알림 및 준비 계획

- 시험, 수행평가, 과제 마감 전 알림
- 이동 중이나 쉬는 시간에도 확인하기 쉬운 짧은 알림 제공
- 목표 기한을 기준으로 반복 일정이나 시험 준비 일정을 분배하는 기능 확장

### 👥 그룹 일정 공유

- 반, 동아리, 스터디, 조별 과제 그룹 생성
- 그룹 일정 등록 및 최신 변경 내용 공유
- 그룹별 접근 권한을 적용해 개인 일정과 공유 일정을 분리
