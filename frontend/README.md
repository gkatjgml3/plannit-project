# PLANNIT Frontend

PLANNIT의 데스크톱 웹 프론트엔드입니다. 별도 프레임워크 없이 HTML, CSS, JavaScript로 구성합니다.

## 현재 구현

- 데스크톱 분할형 로그인 화면
- 아이디·비밀번호 입력 검증
- 비밀번호 표시·숨김
- 로그인 상태 유지, 비밀번호 찾기, 회원가입 UI
- 키보드 탐색과 스크린 리더용 오류 안내
- 작은 화면에서도 입력이 가능하도록 보조 반응형 처리

실제 인증 방식과 서버는 아직 `[미정]`입니다. 현재는 로그인 정보를 외부로 전송하거나 저장하지 않으며, 유효한 입력을 제출하면 서버 연결 전 상태임을 안내합니다.

## 실행과 검증

`frontend/index.html`을 브라우저에서 열면 로그인 화면이 실행됩니다.

```bash
npm test
npm run build
```

빌드 결과는 `frontend/dist`에 생성됩니다.
