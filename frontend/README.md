# PLANIT 프론트엔드

PLANIT 모바일 UI 보드를 기준으로 만든 HTML·CSS·JavaScript 기반 상호작용 프로토타입입니다. 소프트 살몬 포인트 컬러와 따뜻한 흰색·회색 배경을 사용하며, 그라데이션이나 휴대폰 하드웨어 목업 없이 모바일 화면 자체를 보여 줍니다. 내용이 긴 화면은 잘리지 않고 화면 안에서 세로로 스크롤됩니다.

## 실행

저장소 루트에서 정적 파일 서버를 실행합니다.

```powershell
node frontend/server.js
```

브라우저에서 `http://localhost:4173/frontend/index.html`을 엽니다.

## 구현 화면

- 로그인, 회원가입, 약관 동의
- 오늘 일정, 주간 날짜와 빠른 일정 등록이 보이는 메인
- 월간 캘린더, 날짜별 일정 목록, 일정 검색
- 개인·그룹 일정 추가, 상세 확인, 수정, 삭제
- 이미지 선택·카메라 촬영, 미리보기, 분석 진행 상태
- 여러 추출 일정의 확인·수정·선택 저장과 저장 완료
- 클릭 가능한 월~금 전체 시간표, 방과후 수업 추가, 과목 색상·교시 시간 설정
- 그룹 목록, 그룹 생성·코드 참여, 그룹 상세와 공유 일정
- 알림 목록, 마이·설정, 프로필 편집
- 빈 상태, 분석 오류, 권한 안내 등 주요 예외 상태
- 모든 주요 화면에서 바로 여는 하단 `일정 등록` 버튼

## 현재 데이터 처리

현재 화면은 API를 호출하지 않는 프론트엔드 전용 프로토타입입니다. 일정·시간표·그룹의 변경 내용은 `sessionStorage`에 저장되어 같은 브라우저 탭을 새로고침해도 유지됩니다. 이미지 분석은 실제 AI를 호출하지 않고 `createExtractionCandidates()`가 교체 가능한 예시 결과를 반환합니다. 비밀키나 서버 설정은 프론트엔드에 저장하지 않습니다.

## 화면 크기

- 기준 모바일 폭: 최대 430px
- 브라우저가 더 좁으면 화면 폭에 맞춰 축소
- 브라우저가 넓으면 앱 화면을 가운데 배치
- 하단 탐색이 있는 화면과 상세 폼 모두 각자의 긴 콘텐츠를 세로 스크롤로 확인
