# PLANIT Frontend

PLANIT의 데스크톱용 정적 웹 화면입니다. 별도 프레임워크나 백엔드 없이 HTML, CSS, JavaScript만 사용합니다.

## 현재 구현

- 로그인 화면
- 회원가입 정보 입력 화면
- 필수·선택 약관 동의 화면
- 대형 월간 캘린더, 다가오는 일정, AI 채팅 시작 영역을 한 화면에 배치한 메인 대시보드
- 아이디·이메일·비밀번호 입력 검증
- 비밀번호 표시·숨김
- 로그인 상태 유지 UI
- 키보드 탐색과 스크린 리더용 오류 안내
- 하늘색 단색 디자인과 데스크톱 레이아웃
- 프로젝트에 포함한 SUIT Variable 웹폰트

API 호출, 백엔드 연결, 계정 생성 기능은 포함하지 않습니다. 입력값은 현재 브라우저 화면의 동작 확인에만 사용되며 새로고침하면 사라집니다.

## 실행과 검증

`frontend/index.html`을 브라우저에서 열면 로그인 화면이 실행됩니다.

```bash
npm test
npm run build
```

빌드 결과는 `frontend/dist`에 생성됩니다.
