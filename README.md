# 📅 플랜잇 (PlanIt)

> 사진 한 장으로 일정을 등록하는 AI 캘린더

2026 소프트웨어 챌린지 · 참가 주제: **인공지능과 함께 해결하기**

## 소개

학교에서 받은 학습지, 공지문, 시험 안내 자료를 사진으로 찍어 올리면 AI가 내용을 분석해 일정 후보를 만들고, 사용자가 확인·수정한 일정만 캘린더에 등록합니다.
일정 제목, 날짜, 장소를 하나씩 입력할 필요가 없고, 반·동아리·스터디 같은 단체와 일정을 함께 볼 수 있습니다.

```text
📷 사진 업로드 → 🤖 AI가 일정 후보 추출 → ✅ 사용자 확인·수정 → 📅 캘린더 등록 → 👥 단체 공유 → 🔔 반복 확인
```

상세 기준은 [PLANNIT_CODEX_SPEC.md](PLANNIT_CODEX_SPEC.md), 작업 지침은 [AGENTS.md](AGENTS.md), 팀 Notion 운영은 [docs/planning/notion-guide.md](docs/planning/notion-guide.md)를 참고하세요.

## 주요 기능

- **사진으로 일정 등록**: 사진 속 날짜와 내용을 AI가 읽어 일정으로 만듭니다. 여러 날짜에 걸친 일정도 한 번에 등록하고, 준비물·장소 같은 세부 정보도 함께 담습니다.
- **일정 확인·수정**: AI가 만든 일정 후보를 저장 전에 확인하고 고칠 수 있습니다. 날짜가 없거나 모호한 후보는 고치기 전까지 저장되지 않습니다.
- **단체 공유**: 반, 동아리, 스터디 그룹 방을 만들면 올라온 일정이 구성원 모두에게 공유됩니다.
- **알림**: 중요한 일정이 다가오면 쉬는 시간이나 이동 중에 짧게 알려줍니다.
- **일정 자동 분배**: 반복 일정과 시험 대비 일정을 목표 기한에 맞춰 나눠 줍니다.

## 개발 현황

**프론트엔드** ([frontend/](frontend/README.md), 피그마 기준 상호작용 프로토타입)

- **완료**: 로그인, 회원가입, 약관 동의와 약관 상세
- **완료**: 날짜별 홈, 시간표와 수업 설정
- **완료**: 월간 캘린더와 일정 추가·조회·수정·삭제
- **완료**: 이미지 검증·미리보기·분석 상태·여러 일정 후보 확인 및 수정
- **완료**: 마이, 그룹 생성·코드 참여·구성원 확인·일정 공유
- **임시 구현**: 프론트엔드 이미지 분석 결과와 사용자 데이터는 데모용 메모리 상태이며 새로고침하면 초기화됩니다.

**백엔드** ([backend/](backend/README.md), 자동 테스트와 PostgreSQL 실행으로 확인)

- **완료**: 회원가입·로그인·토큰 재발급·로그아웃, 개인·팀 일정과 권한, 준비물·반복 일정
- **완료**: 이미지 분석 후보 검토·확정 흐름(비동기), 원본 이미지 보관 정책, 알림 예약·재시도
- **임시 구현**: AI 분석은 개발용 가짜 분석기, 알림 발송은 로그만 남기는 가짜 발송기입니다.

**미연결**: 프론트엔드는 아직 백엔드 API를 호출하지 않습니다. 서버 인증·PostgreSQL 저장·이미지 분석·알림은 프론트엔드 API 연동 단계에서 연결합니다. 실제 AI 분석과 브라우저 푸시 알림 발송은 아직 없습니다.

## 실행

- 프론트엔드: 저장소 루트에서 `node frontend/server.js` → http://localhost:4173/frontend/index.html
- 백엔드: `backend/`에서 `gradlew bootRun` → http://localhost:8080 (자세한 내용은 [backend/README.md](backend/README.md))
