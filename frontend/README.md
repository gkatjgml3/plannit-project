# PLANIT 프론트엔드

피그마 와이어프레임을 기준으로 만든 HTML·CSS·JavaScript 기반 상호작용 프로토타입입니다. 화면은 402×874 비율의 고정 프레임으로 표시되며, 내부 목록만 스크롤됩니다.

## 실행

저장소 루트에서 정적 파일 서버를 실행합니다.

```powershell
node frontend/server.js
```

브라우저에서 `http://localhost:4173/frontend/index.html`을 엽니다.

## 구현 화면

- 로그인 → 회원가입 → 약관 동의 및 상세
- 날짜별 홈과 빠른 일정 추가
- 요일별 시간표, 수업 추가·수정·삭제, 교시 시간 설정
- 월간 캘린더, 날짜별 목록, 일정 상세·추가·수정·삭제
- 이미지 선택, 형식·10MB 제한 검증, 미리보기와 분석 상태
- 여러 추출 일정 선택·수정·일괄 등록
- 마이, 그룹 목록·상세, 그룹 생성·코드 참여와 일정 공유

## 현재 데이터 처리

현재 화면은 API를 호출하지 않는 프론트엔드 프로토타입입니다. 일정·그룹 데이터와 이미지 분석 결과는 브라우저 메모리에서만 유지되며 새로고침하면 초기화됩니다. 실제 AI 제공 업체와 모델은 아직 정하지 않았고, `createExtractionCandidates()`가 교체 가능한 임시 분석 결과를 반환합니다. 비밀키는 프론트엔드에 저장하지 않습니다.
